# Backend 14 - Maven Libraries & Applications

Dự án bao gồm các module bài tập:

1. **math-lib**: Thư viện tiện ích cung cấp các phép tính toán (cộng, trừ, nhân, chia có xử lý ngoại lệ).
2. **calculator-app**: Ứng dụng Console Maven nhúng thư viện math-lib.jar (thư viện cục bộ trong thư mục lib/) để thực thi và kiểm thử.
3. **quadratic-equation-lib**: Thư viện giải phương trình bậc 2 ($ax^2 + bx + c = 0$) xử lý toàn diện mọi trường hợp (suy biến bậc nhất, vô số nghiệm, vô nghiệm, nghiệm kép, 2 nghiệm phân biệt), tích hợp Unit Test JUnit 5.
